# SafeSpace

A zero-typing, GenAI-powered crisis support tool for individuals navigating substance use recovery, built for PromptWars (Google for Developers × Hack2Skill).

## Chosen Vertical

Substance use disorder recovery & prevention — supporting individuals in crisis/craving moments and their caregivers via a linked, two-role model.

## Approach & Logic

The core design constraint: the moments this app needs to serve are the moments users can least afford to type, read, or think clearly in. So instead of a typical chatbot or form-driven app, SafeSpace uses GenAI for narrow jobs — **classifying urgency**, **generating a personalized calm message**, and **providing caregiver scripts**.



## How It Works

1. **Authentication (Two Roles):** Users sign up as either a Patient or a Caregiver. Patients receive a 6-character Invite Code. Caregivers enter this code at signup to link their account securely to the patient.
2. **Onboarding:** Patients save their name, a trusted contact, and a personal calming phrase.
3. **Patient Flow:** One large button plus a text input accepting English, Hindi, or Hinglish (code-mixed).
4. **Classification:** A Gemini API call classifies the input as `LOW`, `MEDIUM`, or `HIGH` risk.
5. **Caregiver Flow:** Caregivers log in to an AI dashboard. They describe the patient's behavior and receive immediate, customized de-escalation scripts (with "what to say" and "what to avoid saying") generated by Gemini.

## Tech Stack

- Gemini API (`gemini-2.5-flash`) for classification and generative personalization
- **Frontend**: React (Vite)
- **Backend**: Node.js/Express
- **Database**: MongoDB Atlas
- **Auth**: JWT (httpOnly cookies) with bcrypt hashing

## Local Development Setup

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas Cluster URI
- Gemini API Key

### Installation & Configuration
1. Install dependencies in the root:
   ```bash
   npm install
   ```
2. Configure environment variables in the `backend/` directory:
   Rename `backend/.env.example` to `backend/.env` (or create it) and add:
   ```
   PORT=3000
   MONGODB_URI=your_mongodb_connection_string
   GEMINI_API_KEY=your_gemini_api_key
   JWT_SECRET=your_super_secret_jwt_key
   NODE_ENV=development
   ```

### Running Locally
To start both the frontend and backend concurrently, run from the root directory:
```bash
npm run dev
```
- The backend will start on `http://localhost:3000`
- The frontend will start on `http://localhost:5174` (or 5173). Open the frontend URL in your browser.

*Note: If `npm run dev` fails due to port conflicts or orphaned processes, ensure you kill any existing node processes on ports 3000 and 5173/5174 before running.*

## Production Deployment (Vercel)

This application is configured as a monorepo explicitly tailored for **Vercel** with a `vercel.json` file handling the builds and rewrites.

### Deployment Steps:
1. Push the code to a GitHub repository.
2. Log into Vercel and click **Add New Project**.
3. Import your GitHub repository.
4. **Important Framework Setting:** Leave the Framework Preset as **"Other"** (Do not select Vite or Create React App, as the `vercel.json` dictates the build).
5. Open the **Environment Variables** section and add the following:
   - `MONGODB_URI`
   - `GEMINI_API_KEY`
   - `JWT_SECRET`
   - `NODE_ENV` (Set to `production`)
6. Click **Deploy**. Vercel will automatically build the frontend into `frontend/dist` and serve the backend via serverless functions.

## Assumptions Made

- **Authentication:** We use a full JWT + HttpOnly cookie authentication strategy to satisfy the two-role model, departing from earlier stateless assumptions.
- **Emergency Resources:** India-specific emergency numbers (112, KIRAN, Tele-MANAS) were used since the target sector for this build is India.
- **Input:** Input is assumed to be short and informal (voice-to-text or quick typed entry), not structured text — the classifier prompt is written to handle fragmented, emotional, or code-mixed language accordingly.

## Known Limitations

- Only English, Hindi, and Hinglish are explicitly handled by the language processing instructions.
- The Caregiver dashboard currently relies on the caregiver typing their observations; in a production environment, this could be extended to allow voice observations.
